# F5 BIG-IP Advanced WAF (ASM) - documented inspection behavior

Status: documented, not measured (no owned F5 property this session).

## Block signature

Cookie `BIGipServer*`, header `X-WA-Info`, or body containing
`The requested URL was rejected`.

## Inspection limits

F5 ASM body inspection is policy-driven with configurable limits per security
policy; no fixed default is asserted here. Measure live with `find-limit`.

Source: https://techdocs.f5.com/

## Applicable classes

- Size pads target the per-policy body window.
- Parser differentials (JSON/HPP) depend on ASM's application-language
  normalization; F5 ASM parses structured bodies aggressively.
- Encoding (`gzip_body`) depends on whether decompression precedes inspection.
