# Wordfence (WordPress) - documented inspection behavior

Status: documented, not measured (no owned Wordfence property this session).

## Block signature

Body containing `Your access to this site has been limited by the Wordfence
firewall` or `Generated by Wordfence`.

## Inspection limits

Wordfence is a WordPress plugin: its WAF inspects at the PHP layer after
WordPress core loads, and its detection is signature/scoring based with no
meaningful byte-size body window. Body-size pads are therefore not the right
class here.

Source: https://www.wordfence.com/help/website-security/

## Applicable classes

- Payload obfuscation (`sqli_version_comment`, `xss_unicode_escape`) targets
  Wordfence's regex signatures directly.
- The plugin is behind the origin, so transport/encoding tricks that rely on an
  edge inspection point do not apply.
