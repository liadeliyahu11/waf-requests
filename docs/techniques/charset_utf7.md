# charset_utf7

Category: encoding | Risk: conditional | Applies to: aws+cloudflare+akamai | Fidelity: differential

> **Impact:** **Impact: conditional.** The wire payload DIFFERS from the original;
the origin interprets it correctly only if its parser behaves as
documented here. Delivery alone is not exploitation - prove it with
`python -m waf_requests verify <url>`.

## Mechanism
The transform re-encodes the body from UTF-8 to UTF-7 and sets `charset=utf-7` on the Content-Type header. It additionally force-escapes `< > " ' ( ) &` into `+ABw-`-style UTF-7 shift sequences even when plain ASCII would be legal. Signature characters vanish from the byte stream.

## Why the WAF misses it
Signature engines match literal ASCII bytes such as `<script>` or `' OR`. In UTF-7 those characters appear only inside modified-base64 shift sequences, so the byte patterns the rules anchor on no longer exist in the scanned bytes.

## Why the origin still accepts it
The prerequisite is an application stack that decodes the request as UTF-7. Historic ASP and classic stacks did this when the charset declared it. After decoding, the payload characters reappear with their original meaning. Python stdlib codecs round-trip UTF-7, and tests prove integrity that way.

## Wire example

Generated by applying this transform to a representative request (fidelity tier: **differential**).

Original:

```http
POST /search HTTP/1.1
Host: shop.test
Content-Type: application/json
Content-Length: 20

{"q": "' OR '1'='1"}
```

After `charset_utf7`:

```http
POST /search HTTP/1.1
Host: shop.test
Content-Type: application/json; charset=utf-7
Content-Length: 52

{+ACI-q+ACI-: +ACI-+ACc- OR +ACc-1+ACc-=+ACc-1+ACI-}
```

## Prerequisites and limits
- Wins only where the application honors `charset=utf-7` on requests. Modern frameworks assume UTF-8 and will not decode it.
- Fails when the WAF transcodes the body to the declared charset before matching.
- UTF-7 is a legacy encoding. Many intermediaries normalize or reject it.
- Force-escaping benign ASCII changes the byte form of every quoted string, which can confuse applications that compare raw bytes.
